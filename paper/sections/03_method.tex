\section{Methodology}
\label{sec:method}

This section describes our experimental setup, the prompting configurations, the metrics used for evaluation, and the statistical analysis plan.

\subsection{Dataset (Population)}
We extracted a random sample of $N=100$ User Stories from the public dataset published by Rathnayake et al.~\cite{rathnayake2026}. Each sample contains:
\begin{itemize}
    \item A User Story in Connextra format (As a..., I want..., So that...).
    \item Business requirements.
    \item A Ground Truth Gherkin scenario written by human experts.
\end{itemize}
We selected 20 samples from this set to serve as our Pilot dataset (Tuần 7) and ran the final experiment on all 100 samples (Tuần 8) using a fixed random seed of 42 to ensure reproducibility.

\subsection{Model Configuration (Intervention)}
We used the open-source model \texttt{Qwen2.5-7B-Instruct} running locally via the Hugging Face Transformers pipeline. The generation parameters were configured to ensure deterministic output:
\begin{itemize}
    \item Temperature: $0.0$ (deterministic).
    \item Top\_p: $1.0$.
    \item Max new tokens: $1000$.
\end{itemize}

\subsection{Prompting Strategies}
We systematically evaluated three prompting strategies:
\begin{enumerate}
    \item \textbf{Zero-Shot Prompting}: The model was given the User Story and requirements and directly instructed to output the Gherkin scenario and Behave Python step definitions without any examples.
    \item \textbf{Few-Shot Prompting}: We included two concrete input-output examples (templates) in the prompt, showing the exact Gherkin syntax and Behave Python code structure.
    \item \textbf{Chain-of-Thought (CoT) Prompting}: The model was instructed to output its reasoning process ("thinking steps") before generating the Gherkin scenarios and Python code.
\end{enumerate}

\subsection{Evaluation Metrics}
We evaluated the generated outputs using two distinct metrics:
\begin{itemize}
    \item \textbf{Cosine Semantic Similarity}: We extracted the Gherkin scenario from the output and compared it with the Ground Truth scenario. We used the Sentence-BERT (SBERT) model \texttt{all-MiniLM-L6-v2} to encode the scenarios and calculated the Cosine Similarity between their embeddings. The success threshold was set to $\ge 0.80$.
    \item \textbf{AST Parse Rate}: We extracted the Behave Python code from the output and checked if it could be parsed successfully by Python's Abstract Syntax Tree (\texttt{ast.parse()}) library. The success threshold was set to $\ge 85\%$.
\end{itemize}

\subsection{Statistical Analysis Plan}
To validate our results, we implemented the following statistical tests:
\begin{itemize}
    \item \textbf{One-Sample Wilcoxon Signed-Rank Test}: To check if the SBERT Cosine Similarity of each technique significantly exceeds the $0.80$ threshold.
    \item \textbf{One-Sample Binomial Exact Test}: To verify if the AST Parse Rate of each technique significantly exceeds the $85\%$ benchmark.
    \item \textbf{Paired Wilcoxon Signed-Rank Test}: To compare the semantic similarity scores between techniques (e.g., Few-Shot vs. Zero-Shot).
    \item \textbf{McNemar's Test}: To compare the syntax validity rates between techniques.
\end{itemize}
