\section{Threats to Validity}
\label{sec:threats}

This section discusses threats to the validity of our study and our corresponding mitigation strategies, organized according to the framework by Wohlin et al.~\cite{wohlin2012experimentation}.

\subsection{Internal Validity}
\textbf{Sensitivity to Prompt Wording and API Non-Determinism.}
\textit{Threat:} LLM responses can be sensitive to minor prompt wording variations or cloud API non-determinism.
\textit{Mitigation:} All prompt templates were finalized prior to evaluation and included in our replication package. Inference parameters were locked (\texttt{temperature = 0.0}, \texttt{top\_p = 1.0}), and all API requests were logged with timestamps in \texttt{results/full\_api\_log.txt}.

\subsection{External Validity}
\textbf{Dataset Size and Single Model Dependency.}
\textit{Threat:} Our study evaluates a single commercial model (\texttt{GPT-4o}) across $N=500$ user stories from a web application dataset. The findings may not generalize to open-source models or non-web domains.
\textit{Mitigation:} We selected a representative population of 500 industrial requirements from the Rathnayake benchmark. Future work will evaluate additional model families (e.g., Claude 3.5, LLaMA-3) and domain datasets.

\subsection{Construct Validity}
\textbf{Static Evaluation Metrics.}
\textit{Threat:} Sentence-BERT Cosine Similarity measures semantic vector proximity, while Python AST parsing checks static syntax. Neither guarantees dynamic runtime execution against live applications.
\textit{Mitigation:} Sentence-BERT (\texttt{all-MiniLM-L6-v2}) is a standard benchmark metric for semantic text similarity. AST parsing strictly enforces non-syntactically broken code output, providing an objective proxy for compilation.

\subsection{Conclusion Validity}
\textbf{Statistical Power and Type I Error Control.}
\textit{Threat:} Evaluating multiple prompting strategies across metrics could increase Type I error rates or lack statistical power.
\textit{Mitigation:} Non-parametric Wilcoxon Signed-Rank, Binomial exact, and McNemar tests were applied, reporting exact $p$-values and Cohen's $d$ effect sizes at $\alpha = 0.05$. All primary conclusions are supported by statistically significant test results.
