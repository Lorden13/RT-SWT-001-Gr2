Behavior-Driven Development (BDD) test generation bridges software requirements and automated testing, yet manual authoring remains labor-intensive. Existing research lacks empirical comparisons of prompt engineering techniques for joint Gherkin scenario and Python step definition generation using commercial foundation models. We evaluate Zero-Shot, Few-Shot, and Chain-of-Thought (CoT) prompting techniques using GPT-4o via the OpenAI Responses API on a benchmark dataset of $N=500$ user stories from the Rathnayake dataset. Evaluation metrics include Sentence-BERT cosine similarity, Gherkin syntax validation, Python AST parse rate, and content statistics under Wilcoxon and McNemar tests ($\alpha=0.05$). Empirical findings show Few-Shot prompting achieves the highest mean semantic similarity of 0.8218, significantly outperforming Zero-Shot (0.8088, $p < 0.0001, d=0.291$) and CoT (0.7667, $p < 0.0001, d=0.617$). Few-Shot and CoT achieve 100.0\% AST parse rates vs Zero-Shot 99.8\%. We conclude that Few-Shot prompting with GPT-4o provides optimal semantic precision, structural completeness, and syntactic validity for automated enterprise BDD workflows.
